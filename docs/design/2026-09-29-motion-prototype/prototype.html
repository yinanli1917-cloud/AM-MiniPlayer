nanoPod 动效原型

A：设置页「触控板式」演示台 · B：引导里「完成一步」的打勾动画 · C：引导的转场与微交互。三节都可交互；实现规格见同目录 spec.md。

主题

A　设置页：演示台 + 悬停即演示

把鼠标停在窗口里的某一行上：这一行先亮起，停满 150 ms（且移动不超过 4 px）才切换演示；两段之间淡入淡出，同一时间只动一段；离开行后当前这轮演到落在静息帧就停。开关点一下，回放一次到新状态。

排版决定

  • 演示区在窗口最上方，居中的一块 16:9 圆角矩形（创始人定：一整块、规整、不必撑满两边）。三个候选 280×158 / 300×169 / 320×180，圆角 12，与下面分组卡片同一个半径；默认 300×169。窗口仍是 480 × 562，各段的构图都画在 320×180 的底图上再整体缩放，所以三个尺寸看到的是同一构图。
  • 背景是一张安静的桌面壁纸：冷色底（浅色偏淡蓝紫、深色偏靛蓝）加两团柔和的光，圆角 12。面板、胶囊、键帽在上面才不会和 Apple Music 粉抢色；粉色只留给「正在发生的那件事」。
  • 对应关系：悬停行 = 行底色变深（同触控板页的悬停灰）；离开后最后演示过的行保留浅一档底色，告诉你台上是哪一行；台左下角一枚半透明小胶囊写行名和开关状态。
  • 动画节奏照录屏：主运动约 0.9 s，缓入缓出 cubic-bezier(.42, 0, .58, 1)，无过冲；透明度 0.3 s；动作之间停 0.7–1.4 s。

怎么看

  • 「面板」段四行、「快捷键」段两行都有演示。
  • 把「减少动态效果」打开：演示台只显示静帧，切行不淡入淡出。
  • 「0.25× 慢放」对这里也生效，方便看细节。

B　引导里「完成一步」的打勾动画

环外径 28、线宽 5.5，连续粗环，7 步各占 1/7。卡片按 macOS 标准可读档：宽 260、标题 15、正文 13、beat 13。点「完成一步」看整套；连点会打断并合并（环的速度不断，不回头）；最后一步合圈有礼花。

环在已完成 0 / 1 / 3 / 5 / 6 / 7 步时的静止样子（随页面深浅色切换）；圆头、线宽 5.5、轨道 22% 粉；合圈后变实心粉 + 白勾。

触觉 / 声音建议

        触觉：.levelChange 落在「勾落下」那一刻（+60 ms，画面上第一次有东西撞停）；最后一步合圈用 .alignment，落在圆头碰到起点（+600 ms）。beat 打勾同样一次 .levelChange。每次都取新的 defaultPerformer；用鼠标时系统自动无感。

        声音：不加。这是音乐 app，轻响会踩在用户正在听的歌上。若以后要加，只在合圈那一次，且默认关闭。

        舞台左上角的小标签在这些时刻闪一下，只是标记位置，原型不发声不振动。
      

    

  

  
  
C　引导的转场与微交互

  
一块缩小的屏幕，右上角是 nanoPod 面板。S0 → S1 → S2 → S3 →（S4）→ S5 → S6 → S7 串在一起：可以自动播放，可以一拍一拍点，也可以直接用鼠标在面板上做。每一步完成先接 B 节的打勾与火花，再接转场，最后是新卡片。卡片按 macOS 标准可读档：宽 260、标题 15、正文 13、beat 13、链接和按钮 12。

怎么玩

      
    
        
  • S1：控件藏着，卡上的环虚线呼吸，一个幽灵光标从卡的箭头飘向面板。你把鼠标移到面板上，控件浮出，环变实线，beat 2 亮起「待按」。移开，回到提示态。
    • 
        
  • S2：点右上角输出（弹出输出设备小菜单），环跳到左上角 Music；点 Music 完成。可以先点 Music。
    • 
        
  • S3：点左下气泡，面板翻到歌词页。S5：点手势示意（代替双指），面板落到左下角，卡片从面板右侧长出；再点一次，面板收进左边缘。
    • 
        
  • S6：鼠标停到左边缘的小条上，竖卡探出，环从小条跳到竖卡；点竖卡，面板回来。S7：礼花 + 结尾卡。
    • 
        
  • 任何一张卡上：「这一步先不做」（灰掉、不长环、往下走）和「先到这里」（卡收走）。停 6 秒后前者变强调色。把鼠标停在 beat 行上，环会指过去。
