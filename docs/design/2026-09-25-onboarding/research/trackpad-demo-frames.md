# 调研报告 4：系统设置「触控板」页手势演示动画 逐帧拆解

调研代理：Sonnet 5（research，加载 perceive-animation），2026-09-26。素材：创始人自录 `/Users/yinanli/Movies/Omi Screen Recorder/Screen-2026-09-26-113134.mp4`（966×488，60fps，23.8167 s，1429 帧）。全程是「Scroll & Zoom」标签页；画面里实际穿插演示了 4 种双指手势（垂直滑动 / 旋转 / 原地脉冲 / 对角张开），下面按共通规格 + 各手势分列。方法：ffprobe → 10fps 缩略图定位运动窗口（触控板局部逐帧 diff）→ 60fps 原生抽帧 → OpenCV 连通域追踪圆点质心 / 半径 + 固定点采样透明度 → 关键帧目视核对。中间产物在会话 scratchpad，未入仓库。

## 1. 触控板轮廓（t=7.500s 测）

- 位置尺寸（描边中心线）：x 154–342（宽 188px），y 176–318（高 142px），宽高比 ≈ 1.32:1。
- 圆角半径：垂直估 14px、水平估 18px（抗锯齿边缘），取 ≈ 16px。
- 描边：约 3px，核心 RGB(172–175) ≈ #ACACAC–#AFAFAF；真实 alpha 量不到。
- 内部填充：与卡片背景相同 #F5F5F5，即没有独立填充色。无阴影、无渐变。全程浅色模式。

## 2. 手指圆点（4 个手势共通）

- 数量恒为 2。直径：静止态实心核心 22×22px。颜色核心 RGB(107,156,253) = #6B9CFD，运动中色相不变。
- 无独立描边；运动时有同色渐变拖尾（bbox 沿运动方向 22 → 34–48px）；脉冲手势另有柔和光晕。
- 并排静止时中心距 ≈ 32.0–32.7px（边到边 ≈ 10px）。

## 3. 手势 1：双指垂直滑动（去程 + 回程）

- 出现：纯 opacity 淡入淡出，bbox 恒定 26×28（宽松阈值），**没有缩放动画**。
- 顶部静止 350ms，alpha ≈ 1.0。
- 底部静息序列（实测一次）：到达后 300ms 淡到 0.31 → 平台 583ms → 417ms 淡到 0（加速）→ 隐藏 150ms → 433ms 回到 0.30 → 平台 217ms → 233ms 到 0.99 → 待命 480ms。
- 移动：垂直位移 63.0px，水平间距恒定（纯平移）。去程 ≈ 917ms，回程 ≈ 1017ms。
- 速度曲线（去程 progress）：7.133s 0.004 / 7.233 0.037 / 7.333 0.099 / 7.433 0.190 / 7.533 0.310 / 7.633 0.438 / 7.733 0.571 / 7.833 0.706 / 7.933 0.837 / 8.033 0.937 / 8.050 1.000。形状接近标准 ease-in-out（cubic-bezier 约 (0.42–0.45, 0, 0.55–0.6, 1)），无过冲；最后约 6% 位移在一帧内贴合终点（手势 2、4 也独立测到同一特征）。
- 拖尾：bbox 高 22 → 最快时 34–38px，只沿运动方向拉长，同色渐变。
- 一次完整循环（起动 → 顶 → 回底 → 静息序列）≈ 917 + 350 + 1017 + 2810 ≈ 5.1s。无箭头 / 残影等辅助元素。

## 4. 手势 2：双指旋转

静止姿态两点关于轮廓几何中心对称，半径 ≈ 45–46px，弦长 ≈ 92px；同向旋转约 90°，≈ 984ms，同一缓动家族；末帧瞬时贴合。

## 5. 手势 3：双指原地脉冲

位置不动；两点半径同相位呼吸 ≈ 10.3 ↔ 18.7–19.0px，周期 400ms（谷到谷），约 2 个周期后稳定在 ≈ 13.4px；结构是实心内核 + 柔化外扩光晕。

## 6. 手势 4：双指对角张开

起始弦长 28px，中点在轮廓中心；对称外扩到 111.3–111.6px（约 4 倍），≈ 920–970ms，同一缓动家族；末帧瞬时贴合。视频里没有合拢回程。

## 7. 可复现规格（共通）

```
dot diameter 22px (rest); color #6B9CFD; rest spacing ~32px center-to-center
trackpad outline 188×142px, corner-radius ~16px, stroke ~3px #ACACAC, no fill, no shadow
primary motion ~0.92–1.02s, easing ≈ cubic-bezier(0.42, 0, 0.58, 1), no overshoot
quirk: final ~6% of travel snaps in one 60fps frame (do not replicate unless pixel-exact fidelity is required)
motion trail: same-hue gradient opposite travel, length scales with speed (22 → 34–48px along travel axis only)
idle breathing: opacity-only 1.0 → 0.31 → 0 → 0.31 → 1.0, no scale
```

动效描述句：两枚蓝色圆点代表双指，在触控板轮廓内做缓入缓出的位移 / 旋转 / 张合，尾部拖出与速度相关的同色渐隐轨迹；静止时圆点原地呼吸式淡入淡出，模拟手指自然停留于板面。

## 8. 量不到 / 局限

圆角精确值（14–18px）；描边真实 alpha；静息序列是否固定周期（只测一次）；脉冲光晕的径向 alpha 曲线；旋转回程与张开合拢的落位（被截断 / 未出现）；精确 cubic-bezier 控制点（范围估计）；画面里没有设置项文字标签，手势名称是按轨迹形状的描述性命名。
