## Reading

Tick 35 (t=-0.000s, exactly the boundary) is the tick `mainTextLayerHidden` flips false->true and `activeLineDrawLayerHidden` flips true->false — the production swap from the CATextLayer whole-line dim base (`mainTextLayer`) to the bitmap single-pass active-line renderer (`NativeLyricsActiveLineDrawLayer`, `applySinglePassActiveLine`). The row's own FRAME origin (`frameY`) does not move that tick. The rasterized ink right edge moves -0.5 device-px (0.25pt at 2x). NAMED CHANNEL: the two rasterizers (CATextLayer.render(in:) and NSLayoutManager.drawGlyphs via NativeLyricsActiveLineDrawLayer.runImage) round the same glyph run's bounding box to a different device pixel at the moment of the swap — a real, sub-pixel geometry discontinuity, distinct from (and additional to) the ink-density parity NativeLyricsActiveLineInkParityTests already pins. This is pinned as a hard-failing assertion in this file (the swap-tick block) — see 'Fixed / left failing' below.

The two LATER jumps (tick 44 t=+0.075s, tick 61 t=+0.217s, both on `top`, both -0.5px) are a SECOND, smaller channel: each lands mid-line, well after the swap, close to where a new word's active/float phase would begin for this fixture's per-word timings. `NativeLyricsActiveLineDrawLayer.runImage` rounds each run's bitmap size UP to the next device pixel (`Int((frame.width/height * scale).rounded(.up))`) independently per run, so successive words can each pixel-snap by a different sub-pixel remainder — plausible but NOT independently isolated/pinned here (lower priority per the task; left as a report-only finding, not gated).

CIFilters (the stepped blur, springed-blur v28 arm) cannot run under headless `layer.render(in:)`, so this measurement cannot see or rule out a blur-related contribution on top of these two channels — consistent with the founder's report that toggling the blur arm live did NOT fix the twitch: the swap-tick channel found here is upstream of blur entirely (blur is applied to already-rasterized ink; this jump is a difference in WHERE that ink is before blur ever runs).
